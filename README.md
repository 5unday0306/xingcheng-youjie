# 行程有解

为结伴旅行者协调条件、查看真实地图并比较修订。当前太原动态规划边界为1～6人、1～2天，使用已有四处来源候选和两日餐饮候选；输入仍可保存1～3天，但3天在动态生成前明确拦截。模型分别协调、逐人筛选、基于道路核查的组合选择和审查，程序独立计算预算、逐日步行、时间及锁定。未知与冲突保留，不保证旅行可行。真实动态验证状态见`docs/太原动态规划与纠错验收.md`。

## 环境与离线快速体验

应用依赖Node.js 24（实测24.19.0，支持>=24 <25），无第三方运行时依赖。无需npm install，不需要账号即可体验输入、保存恢复和明确标注的固定替身；浏览器建议使用本轮实际测试的Microsoft Edge。

```powershell
node --version
node scripts/setup-project.mjs
node server.mjs --offline-test
```

打开 http://127.0.0.1:4174 。此模式没有真实模型、地图或道路请求，结果为固定受控样例。`npm start`为普通准备模式4173，真实入口禁用。不能双击HTML代替启动服务。浏览器存档按域名/端口隔离，localhost和127.0.0.1也不同。

动态输入演练：运行`node server.mjs --dynamic-offline`，打开 http://127.0.0.1:4176 。此模式用关键词角色和固定合成道路矩阵验证不同条件如何影响组合，不是真实模型或真实地图，不绘制合成几何。无需凭据，不写正式方案私有存档；演练采用/锁定只在该服务内存中，重启清除。需求保存仍用本端口浏览器版本1存档。可比较偏好、预算、步行、人数、时段与日期，再锁定午餐并修改条件。真实语义理解及实际路线必须在有效授权下另验。

node scripts/setup-project.mjs --real --confirm-authorized
node server.mjs --real-preparation --case06

确认标志表示你已具有本次调用与用途授权；首次初始化只建立空授权/账本，不复制旧私有数据、不发请求。若缺少.env，脚本仅创建空模板并停止。若已有私有状态，初始化不会覆盖。旧任务08授权不自动覆盖动态规划。动态真实验证须先有明确新授权，再显式执行`node scripts/activate-dynamic-input.mjs --confirm-authorized`并重启正式服务；该命令不会由页面或启动自动调用。当前本机四次启动（含一次另行批准的恢复）已用完，只读历史；不通过再次运行激活命令绕过限制。失败后先诊断，不盲目清停止并重试。

打开 http://127.0.0.1:4177 。默认不联网：

1. 编辑条件后点击主操作；地图准备、已有地点复用、候选筛选、道路和四角色依次执行。已确认的测试地点/午餐不重选；缺少已知地点时检索，只在歧义、入口或失败时要求确认。位置只是测试落点，不冒充官方入口核验。
2. 查看地图和活动，展开角色查看逐人匹配、组合取舍及实际交接。组合可删除、换日和重排非锁定活动，限于四处有来源候选；每轮最多核查8个组合/32次道路工具尝试、6模型、两轮、12分钟、并发1，无自动重试。未查组合不称无解或最优。
3. 午餐卡可查看依据、换店和锁定计划时间；当前保存的11月8日12:30～13:30锁定保持。自行编辑希望改变的逐人步行/预算/时段后重排，系统不会自动将步行改4公里。原方案与新条件分开，预览须明确接受。
4. 有冲突/上界风险的失败候选不可采用；拒绝不撤回4公里。可显式解锁或再决定取舍，不自动放宽条件、移动锁定、降低内部估计。
5. 点击保存方案状态；选择当前采用或修订预览导出HTML/JSON。保存/导出不等于接受。可读HTML可由浏览器打印，但不是比赛技术PDF。

## 保存、恢复与数据边界

- 需求存档兼容版本1；损坏/不兼容时提示，不静默覆盖。锁定和采用版本另有格式版本，原方案及预览关联需求版本。
- 刷新不自动调用模型、道路或SDK。服务重启恢复用户输入、确认点/餐厅、锁定、采用引用和自有活动结构快照；缺少原始道路时明确提示，需手动重取。历史结构快照不冒充可直接显示的真实地图回放。真实道路仅在当前服务内保留，超过30分钟不能用于新的重排或采用；需显式重新核查，系统不会自动付费刷新。
- 当前导出白名单只有用户输入、锁定、活动结构、版本及独立估计，不打包图面/瓦片、坐标、原始道路、上游交通数值。完整交通/费用仍需在应用核查，文本导出不代替地图功能。用户声明已有额外许可，许可文件尚待本机复核；不据此默认扩大导出。见[高德协议](https://lbs.amap.com/pages/terms/)。
- 私有授权、账本、原始开发聊天与未公开地图证据均在Git忽略的docs/private/；真实.env不纳入版本。旧轮次证据保留，对外再使用仍需核对许可。
