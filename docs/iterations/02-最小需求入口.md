## 实现

- 原生HTML/CSS/ES模块，Node.js标准库静态服务，仅绑定127.0.0.1:4173；无第三方应用依赖。package-lock记录当前依赖状态。
- 太原3人2天固定测试需求预填，支持1～6人、1～3天；唯一可选城市为太原。日期由开始日期+天数计算，连续日期作为结构化结果。
- 每人稳定ID、匿名显示名、独立偏好、个人全程预算及按天步行上限。减少人数或天数先确认，取消不丢失输入。
- 中文字段错误、空值不转零、布尔不作数字、非有限及负金额/距离拒绝；不自动放宽约束。
- 仅手动保存有效需求，格式版本1；打开同地址自动恢复，损坏/不兼容不覆盖且恢复前输入保留。显式确认后才替换旧存档。
- 摘要逐日逐人显示，始终说明旅行可行性未验证；列出实际落点、开放预约、午餐、交通、内部步行缺口，不创造午餐锁定项。
- 使用textContent显示用户内容；HTTP白名单只提供五个前端文件，CSP connect-src none，配置和仓库路径404，不向浏览器下发密钥。

## 用户验收

1. npm start，打开http://127.0.0.1:4173，检查默认摘要，核对逐人偏好、600元及6公里和公共测试点。
2. 改一人需求后保存并刷新，再试1人1天与6人3天（新增成员需填写偏好）。减少操作先确认，其他人不被误改。
3. 空预算或结束早于开始应出现中文错误并保留输入；页面始终保留旅行可行性未验证提示。
