# 调整预览显示绑定修复

日期：2026-10-31。范围为用户反馈“点击调整行程，当天安排没有变化”。

## 已证实原因与修改

planning.js在工作流切换时先发异步状态同步，再立即将未采用结果强制设为original。因此即使角色完成且已有预览，活动仍是“原方案（保留）”。候选控件视图也可能不同步。

移除强制原方案：只读同步取得状态后显示当前选中预览及候选控件；已明确拒绝时显示原方案。用户仍能主动查看原方案。新规划或手动重试进入预览视图。地图与活动继续共用result及paint，不自动生成或采用。尚无预览时保留基线，明确生成后才有调整结果。
