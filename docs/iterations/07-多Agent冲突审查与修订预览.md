## 实现检查点

- 原路段和核查器复用；加入仅服务器可设的公交strategy=3。官方当前v3文档：https://developer.amap.com/api/webservice/guide/api/direction ，2026-10-29核对：3为少步行，默认0。并不保证最优、可用或达标。
- 四个角色分别请求模型，使用上游实际产出及SHA256引用，不把一次回答拆角色。角色只选择已有交通关系，不能提交坐标、道路、票价或约束修改。程序比较真实路段，只有较少步行才放入预览，同时核算时间/费用/逐人步行。
- 不改变已确认地点与午餐；本轮先比较接驳策略。地点/午餐变更仅作为后续需用户取舍事项，不静默实施。内部步行区间、停留范围和未知保持。
- 正式工作台新增协作区：真实节点、输入/结构化产出、来源、原/预览对比、接受/保留。启动是显式操作，刷新只读状态；输入/落点变更取消在途，迟到输出不采用。
