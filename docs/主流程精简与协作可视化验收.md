## 失败与修复记录

1. 第一轮166/167：旧测试允许仍有步行上界风险的07候选采用。保留首次失败TAP；修正为分别验证风险拒绝和估计范围内接受，不删除服务端保护。
2. 浏览器直达重排会自动展开锚点所在设置：拆开工作区锚点与锁定编辑区域。
3. 原测试等待已折叠的内部按钮、期待6份重复个人卡：改从主操作验证，检查合并显示仍涵盖各人；空状态文案更新后同步断言。
4. 首次连续流程的合成道路过短，没有可比较公交候选；后续合成接驳过长导致第1天风险而禁止采用。测试分别设有依据的合成接驳/外部路段，正常覆盖角色与可接受分支；没有修改真实道路、步行估计或个人上限。15秒等待不足，改为90秒测试等待，不改变生产调用上限。
5. 自查手机头部日期裁切，增加局部高度；四节点间距收紧；Esc返回重排的锚点丢失已修复并有专门断言。最终增加模式按钮切换后Esc用例，发现关闭和URL更新相隔一帧；改为同步关闭及导航恢复，25项导航通过。切到无结果模式清空旧地图展示，不调用接口。
