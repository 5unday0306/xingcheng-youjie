# 多人协商方案对比交付记录

记录日期：2026-10-31。产品尚未冻结，等待用户体验确认。

## 实现

- 同轮最多8个有界组合，最多3个结构或交通有差异的对比候选，共享有效道路缓存；逐案保留程序核查、资料时间及审查结论，不以同方案换标题凑数。
- 协调独立输出逐人需求与建议；筛选逐人评分进入排序和覆盖核算；规划使用筛选交接和工具核查；审查实际收到全部对比候选，逐案返回取舍及是否需修改。模型评分不是满意度。
- 地图旁提供候选快捷切换，详细卡片展示每日活动、交通、时间、步行、个人费用、偏好覆盖与未覆盖项、未知和锁定。查看不采用；接受仍受数值、锁定、道路时效及审查保护。
- 普通页面移除结构化需求、稳定ID和地点维护；独立开发模式通过 ?developer=1 查看。历史与替身标识保留，重复版本条件合并。
- 候选几何仅在会话内存，私有执行快照不含几何；重启不恢复全部候选地图，也不自动重取。保存导出只含允许的结构。原采用版本和12:30～13:30午餐锁定未替换。
