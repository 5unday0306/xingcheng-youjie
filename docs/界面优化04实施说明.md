## 设计取舍

采用旅行准备册：画布#F4F7F5、正文#183D35、操作#226A54、插画底#DCEAE1、辅助#64746C、点缀#E7B963。字体Segoe UI搭配Microsoft YaHei；目的地32px/手机26px，正文14～16px，辅助至少12px。信息左对齐，8px间距节奏，360px编辑栏。

```text
行程有解  旅行准备                           太原试点
编辑条件 │ 太原/实际日期/人数/天数     原创城市意象
折叠成员 │ 路线准备 / 需求摘要
         │ 紧凑未接入说明+真实检查入口 │ 当天条件
固定操作 │ 伙伴需求概览：头像/原话/个人限制/编辑
         │ 可展开资料缺口
```

复核：不能把03的大地图块换成绿色继续占屏。将视觉重心交给140～180px目的地横幅和有当前数据的同行者概览；路线空态限制160～220px，且具备复用原校验的真实操作。摘要改为整行准备单、检查后收起大表单，保留修改需求。768～1024切换单工作区而非挤压双栏。SVG双塔、屋檐与山形仅是原创非地理城市意象，不展示真实地点或地图。

城市名与意象引用集中配置；日期空值显示待填写，人数/天数来自当前draft；匿名头像用固定序号，不下载人像。详情仍保留原话，不对“必须去”等自动分类。版本1、校验、确认及存储规则不变。无新增接口请求、无.env读取。
