# 旅行策划台：独立设计预览

日期：2026-10-25。起点e9b69b5。依据UI升级方案-旅行策划台.md及本轮用户请求，使用本机frontend-design Skill。本轮是视觉方向预览，不集成正式应用，05B暂停。

## 先设计与复核

色彩：深蓝#173247、瓷白#F6F8FB、面板白#FFFFFF、正文#202D3A、次要#526477、铜橙#B65C31。警告独立使用褐黄文字与浅黄底，铜橙只作日期/品牌强调。采用本机Microsoft YaHei/Segoe UI正文，目的地标题用本机中文宋体及可靠回退，不加载字体。

布局：紧凑品牌栏与旅行标题，上部固定双状态切换；桌面左侧344px需求清单独立滚动，中央活动/准备单与右侧280px核查共用工作区滚动；中等及手机单区域切换，内容左对齐。主视觉为旅行标题与日签的排版，不再让装饰横幅占据结果空间。

```text
行程有解  旅行策划台                       设计预览
太原 / 实际日期与人数        需求编辑 | 固定离线样例
需求清单 / 同行者       每日安排 / 准备单       核查信息
展开编辑               活动序列 / 用餐未知      公共缺口
真实的预览操作         返回集合点条件           个人限制
```

自评修订：深蓝顶栏加同尺寸卡片仍会像通用后台，因此不做侧边导航/统计卡/装饰插画；将旅行可用时段与活动到离时间分开，使用清单、日签、活动条目和核查账页各自的层级。列表细线仅表示顺序，不表示道路；不在准备状态画活动节点。

隔离：独立preview/planning-desk及4175服务，仅提供自己的三份前端文件，禁止connect。无需修改正式server/web，不能访问正式存储或API。编辑在内存，固定样例与编辑内容分开；切换样例不覆盖预览编辑，样例不声称响应这些修改。不提供虚假保存、生成、分享、导出动作。

素材：本项目原创行李标签SVG与CSS序号头像，无新增照片、字体、图标或第三方应用依赖；Skill来源/许可沿用第三方设计工具.md。后续截图自查、问题及结果按实际追加。

## 实现与自查

独立路径preview/planning-desk，专用Node内置服务4175，不修改正式server.mjs、package.json、web、lib、data。数据为太原3人2天匿名测试案例：编辑状态在内存；固定样例使用独立快照，切换不覆盖预览编辑，也不把编辑后的需求套成已生成结果。

准备状态不绘制活动节点；样例按任务05已有候选顺序展示山西博物院/用餐待选/迎泽公园，以及钟楼街/用餐待选/食品街。150/45分钟等仅固定样例停留估计，不制作到离时间或道路。全程费用已知部分30～60元仅为食品街逛吃估计，每天步行与时间缺口保持未知；公共资料集中，个人全程预算和当天步行单独展示。

真实自查与修正：首版旅行条件默认展开使个人编辑偏低，改为默认收起并保留可展开编辑；删除重复活动分类说明，缩紧公共核查区，使首屏能看见更多活动及个人核查。首次跨宽度测试因为脚本重复点击已打开的成员而将其关闭，字段矩形检查失败；改为仅在关闭时展开，不删除断言。后续截图发现还原仍保留旧滚动/展开状态，已在切换后重置滚动，并让还原恢复默认展开状态，新增首位成员实际可见性检查。移除一个没有信息作用的装饰符号。

已查看最终桌面编辑/样例、手机编辑/样例/核查截图；手机还原后的首位成员、主操作及长文本均可到达。固定操作区独立占空间，不覆盖末尾字段。窗口内部仍需按内容滚动，截图不代表全部内容同时在首屏。
