## 账号准备

2026-10-24重新打开官方入门文档核对，未登录账号、未操作注册或创建密钥。

1. 用户自行在[高德开放平台](https://lbs.amap.com/)注册并按平台要求完成个人开发者认证；在控制台创建“行程有解”应用，添加服务平台为Web服务的Key。最小路段测试只需Web服务Key，前端JS类型Key可后续再准备。按控制台检查实际额度和用途许可，暂不购买升级服务。依据：[官方Key获取指南](https://lbs.amap.com/api/webservice/guide/create-project/get-key)。
2. 用户自行在[DeepSeek开放平台](https://platform.deepseek.com/)注册，在API keys页面创建项目专用Key，并查看余额与计费说明；需要充值时先决定是否接受费用，不预设赠送额度。依据：[官方首次调用文档](https://api-docs.deepseek.com/zh-cn/)。
3. Key只在本机配置，不发聊天、不放截图或源码。账号准备完成后告知“两个账号已准备”；再安排受忽略的本地.env配置及限额调用。当前没有.env，也没有读取或展示密钥。
4. 实际测试前另行明确允许的调用费用上限，建议按少量请求核查，不开启自动充值或无上限重试。
