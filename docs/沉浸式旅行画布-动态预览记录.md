# 沉浸式旅行画布动态预览

日期：2026-10-25。起点c4dc10a。用户反馈上一版仍不好看，希望动态且更有品质感；本次重新构图，不把上版三栏当作固定布局。05B暂停，本轮只交独立动态预览，确认后才集成。

## 设计与复核（实现前）

使用本机frontend-design Skill。色彩：深海蓝#073B4B、夜海#062A36、冰川青#ADE2DD、浅冰#EFF7F5、正文#173E49、暖橙#EEA06B。采用本机中文宋体作目的地展示、Microsoft YaHei/Segoe UI作界面正文，无远程字体。

构图：宽幅原创山形与建筑剪影形成远、中、近景，实际日期与人数融入前景旅行票签。目的地大字留独立阅读空间；不以大片渐变替代图形。同行者横向概览后接一个主工作区；编辑是侧抽屉，手机为有明确关闭按钮的底部面板。

```text
行程有解                           设计预览
太原 / 日期人数       山形—城影—票签（艺术意象）
同行者1       同行者2       同行者3     展开编辑
需求概览 | 需求摘要 | 固定离线活动       检查 / 暂存本页
主内容（按状态转换）              公共缺口与个人核查
```

自评：避免把上版三栏加深底色继续使用。删去常驻长表单、独立等权核查栏和统计卡组；以场景主视觉、可选择同行者与展开编辑建立空间关系。活动细线仅表示列表顺序，绝不作为地图道路。

动效：首次只播放一次分层进入；选择同行者、打开/关闭编辑、切日和检查成功均使用短暂有限过渡。输入节点不重建，关闭恢复触发点焦点，减少动态偏好下不播放位移动画。暂存只写内存并真实反馈，不做保存到正式应用的假提示。

边界：预览独立4176端口与路径，业务校验复用现有纯函数，不导入存储操作；没有.env、模型、地图、地点和道路请求。离线活动是独立固定样例，时间/道路未知，模式显式标记。原图形原创，不含实景或真实道路；不引入图片、字体、完整模板或新应用依赖。

## 本轮实现

- preview/travel-canvas独立目录与4176服务。只提供自己的HTML/CSS/JS及现有web/core.js纯函数模块；CSP connect-src none，没有API、凭据或正式页面文件路由。
- 四状态：主视觉与同行者概览、桌面侧抽屉/手机底部编辑、现有规则实际校验后的摘要、独立固定离线活动。固定样例不套用编辑数据，切回概览仍保留本页修改。
- 暂存通过structuredClone复制有效需求到内存快照，状态真实区分尚未暂存/已暂存/修改；不调用Storage、后端或磁盘，刷新后清空。关闭或Esc保留本页编辑，文案为关闭面板而非取消修改，错误不丢输入。
- 首次SVG远/中/近层、标题和票签均为有限动画；选择、打开/关闭、切日、检查摘要与暂存反馈使用160～280ms有限过渡。没有粒子、循环漂浮、鼠标光球、视频背景、模糊玻璃或假进度。
- 默认太原三人两天。固定样例停留150/45分钟等沿用任务05测试，非模型结果或实测；道路、到离时刻、用餐与当日开放资料保持未知，界面说明输入检查不代表可执行。

## 截图自查与修正

首批手机截图因浏览器刷新恢复旧滚动位置而没有显示主视觉，已让此独立预览采用手动滚动恢复、首次回到顶部，新增初始scrollY断言。手机山形可能落在白色标题后，已添加仅在手机生效的深色遮层，并将遮层铺满主视觉消除底部硬边；不是仅凭DOM背景色推断所有插画覆盖区域的对比度。票签保留在桌面，手机简化装饰但保留日期人数。

长文本压力摘要与默认案例截图分开，避免把压力内容当作默认设计。保存反馈在截图前等待结束，保留反馈本身的实际交互验证。已查看桌面概览/编辑/摘要/离线、手机概览/编辑/错误/摘要等图，以及实际视频抽取关键帧；没有制作故障满足材料要求。本轮未发生功能断言失败，问题来自真实截图自查。

## 实际操作录屏

本机未发现可直接使用的ffmpeg命令，使用Edge CDP screencast采集真实页面JPEG帧，并由独立浏览器MediaRecorder编码。录屏没有合成应用界面，也没有把静态图串成伪操作。录制墙钟33.01秒，1440×900，WebM/VP9约3.6MB，无声音/鼠标指针。

实际顺序：进入页面→选同行者2→打开编辑→逐字输入原话→改本人预算520元→应用关闭→进入固定样例→第2天/第1天切换→返回概览→检查并转摘要→暂存反馈。均由真实DOM操作执行，不作为用户反馈或用户满意度证据。

文件verification/ui-canvas-operation.webm；动作时间、真实帧数及零外部请求记录在ui-canvas-recording.json。ui-canvas-video-check.json确认解码尺寸1440×900，已成功定位并抽帧2/8/19/26/30秒，查看了其中代表帧。MediaRecorder WebM容器未提供有限duration元数据，33.01秒指实际录制墙钟时长，播放器兼容性或拖动体验可能不同，不将缺省元数据冒称精确容器时长。手机最终遮层调整不影响这份桌面录屏画面。
