# 旅行工作台界面设计说明

日期：2026-10-24。任务03，先设计后实现。使用已安装frontend-design Skill（Apache-2.0，来源与本地指纹见第三方设计工具.md），不复制旅行应用模板。

## 主题与主要任务

为一起出行的朋友整理不同需求，先检查输入，再为后续真实每日路线腾出中心位置。页面是持续编辑的工作台，不是宣传页；当前不生成路线，空态必须直接说明尚未生成、未接地图。顶部只保留项目名、城市/旅行范围和存档状态。

## 设计标记

- 画布灰蓝 #EDF2F8：编辑区外围和应用背景。
- 正文深蓝 #172F4D：标题与高权重内容。
- 交互蓝 #265DCE：主操作、选中日及焦点。
- 面板白 #FFFFFF：可编辑内容与摘要正文。
- 活动橙 #B66120：待核实状态，不用于表示活动已生成。
- 分隔灰 #D5DEEA：对应工作分区和表单分组；不以同尺寸圆角卡片切碎所有内容。

中文使用本机等线DengXian优先，回退Microsoft YaHei和无衬线字体；不请求外网字体。界面标题24px，分区标题17px，表单/正文14px，辅助说明12px；正文行长限制约70汉字以内。4/8/12/16/24px间距，工作分区16px、字段间距12px。重要数字仅用于真实人数、日期和个人限制，不制造运行统计。

## 空间结构

桌面左右对齐，顶部紧凑；编辑和主要展示各自滚动，操作栏位于编辑容器的非滚动底部，不浮盖字段。主要区域占约三分之二，路线是默认视图。

```text
项目名  太原旅行工作台                     存档状态
┌需求编辑 360px─────┬每日路线 / 需求摘要────────────┐
│出游条件（紧凑）    │日切换  第1天  第2天            │
│每日时段           │                               │
│同行者折叠条目      │地图准备：尚未生成本次路线        │
│每人原话与个人限制  │（无底图、无假地点、无装饰路线）  │
│独立滚动           │                               │
├操作栏────────────┤当天时段与公共往返点 / 待补资料   │
│检查 / 保存 / 恢复  │需求摘要另页签逐人展开           │
└─────────────────┴───────────────────────────────┘
```

手机采用编辑需求/需求摘要/每日路线三个视图，主操作仍在编辑视图底部独立操作栏；每屏有清晰返回编辑入口，不再把6人表单与摘要上下相加为超长单页。平板压缩编辑栏至320px，375/390宽时一列视图。摘要和地图准备均有自身可访问标题。

## 计划复核与调整

最初“左表单+右卡片”仍容易成为通用SaaS卡片模板；调整为日签式旅行工作台：主展示用一块大幅路线空态和紧邻的当天条件，编辑成员以连续折叠条目呈现，不增加宣传大标题、渐变或假运行指标。用真实日期串起需求与未来路线，地图区域保持无地理形状的空白底板，避免误认为已接入。橙色只提示资料缺口，蓝色只用于操作与选择。

## 必修交互

- 恢复/覆盖/减少/步行覆盖分别配置弹窗标题、正文、确认和取消；取消及Esc不改变输入。
- 存档状态按草稿与最后保存内容比较，检查状态单独显示；编辑后明确有未保存修改，改回原值可消除该标记；恢复后需重新检查。
- 字段错误关联aria-invalid、aria-describedby；错误列表链接可导航并展开对应成员；修一项重新校验其余错误，不清空所有错误。
- 检查通过切到摘要并定位标题；提供返回编辑。JSON、稳定ID收进开发详情。
- 本人第1天步行复制到其余天是显式操作；若覆盖不同值先确认，不改其他人限制。
- 版本1存档延续既有格式，不迁移或清空现有数据。无新模型/地图请求，不读取.env。

## 素材与截图评审

仅本项目原创CSS与内联图形/文字，不新增图标库、远程照片或字体。地图空态图形仅是折页文档符号，不绘制地理地图或连线。实际前截图为task03-before-1440/390.png；后续对1440/390截图评审，并在375/768/1024检查关键布局、操作可达与错误导航。没有真实手机验证时明确列为未验证。

## 实际截图评审

已查看1440px重构前长表单、重构后每日路线与摘要、390px编辑与路线，以及恢复弹窗截图。桌面地图准备区成为主要视觉面，需求编辑保持独立滚动；手机主要操作在独立底栏，输入和摘要不再串成超长页面。没有添加虚构景点或路线；折页符号仅为空态。测试检查375/768/1024及两端视口的六人三天导航、操作栏位置和焦点。截图只是视觉与本次状态证据，不代表真实手机或全量无障碍验证。

实现后的重点约束：左侧滚动区域需要在其中滚动才能编辑下方同行者，底部操作栏留有独立空间，不遮盖字段；右侧路线和摘要各自切换。更小屏幕/实际软键盘仍待真机核验。
