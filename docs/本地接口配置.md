## 填写方式

根目录 `.env.example` 是无密钥模板；本轮已在文件不存在时复制为 `.env`，不会覆盖已有文件。

用本机文本编辑器打开项目根目录 `.env`，在等号右边粘贴对应密钥，每项一行，不需要添加引号：

```dotenv
AMAP_WEB_SERVICE_KEY=
DEEPSEEK_API_KEY=
```

- 第一项为高德开放平台应用内“Web服务”类型的Key，不是地图JS类型Key。
- 第二项为DeepSeek开放平台创建的API Key。
- 不在聊天、截图、文档或源代码中公开密钥。保存后只需回复“已配置”。
- 这里只是文件配置，未实现应用读取或运行脚本；下一次验证会以不输出密钥的方式检查是否已填写，再决定是否请求接口。

## 任务05：JS Key与安全密钥的本地配置步骤

2026-10-24核对[高德JS API 2.0安全密钥官方说明](https://developer.amap.com/api/javascript-api-v2/guide/abc/jscode)与[准备说明](https://lbs.amap.com/api/javascript-api-v2/prerequisites)。采用serviceHost代理：JS Key供浏览器加载SDK；配套安全密钥由服务端补入上游请求，不使用前端明文securityJsCode方式。代理前缀为`/_AMapService`，配置须早于SDK加载。官方示例允许Node代理，本项目将进一步收紧路径及参数。

1. 在本机编辑器打开项目根目录`.env`，保留原有Web服务Key及DeepSeek配置；**不要用模板覆盖已有文件**。本轮只改无密钥模板，不读取、追加或覆盖你的真实.env。
2. 仅在缺少时追加下面两行，将等号右侧分别填成你已创建的JS API Key及该Key配套的安全密钥。不要把Web服务Key填到JS项，不要创建重复行：

   ```dotenv
   AMAP_JS_KEY=
   AMAP_JS_SECURITY_CODE=
   ```

3. 保存文件。不要粘贴到聊天、截取凭据页面、放进web目录或提交Git。若需要说明进度，只回复“JS两项已在本地配置”。JS Key将按SDK协议在浏览器网络请求可见，不能承诺隐藏；安全密钥、Web服务Key、模型Key必须留在服务端。
4. 在高德控制台检查该Key的服务类型确为JS API、配对安全密钥、应用用途/权限和域名限制。当前开发访问地址为`http://127.0.0.1:4173/`；按控制台实际接受的域名规则设置本地测试范围。未在本轮登录核查控制台，不保证127.0.0.1白名单条目被接受；若被拒绝，把不含Key的错误文字告知开发，不擅自关掉安全限制。
5. 查看账户实际配额、计费及可用的消费限制；不自动购买、充值或认证。配置就绪仅表明填好，不代表接口验证成功或费用已授权。
6. 任务05服务实现后，重启本地服务才读取新增变量；届时配置状态仅显示缺少哪项/是否就绪，不回传值。**当前npm start仍是04静态服务，不读取这些变量，没有代理或配置检查接口，填好后页面暂时不会出现地图。**不要为验证而重跑首次探测脚本。

待实现的安全边界：仅127.0.0.1监听、同源访问校验、固定HTTPS上游与允许的端点/方法/参数、请求大小/并发/超时/额度限制，拒绝任意URL、重定向及客户端传入密钥；服务端注入安全密钥并脱敏错误。静态白名单和CSP按实测必要域名逐项开放，禁止暴露.env；初始页面和配置状态检查不触发地图或模型。SDK相关实际端点及资源请求尚待授权后核对，不预先开放整个通用代理。

本节仅提供配置方法及实施要求，未检查真实配置、未验证控制台权限/代理连通性、未初始化地图。本轮打开官方文档不等于调用业务API。
